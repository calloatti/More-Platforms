<p>Think that the current platforms limit your creativity? Then this mod will let you add 4 new platforms to the game which can be build to the side of any building, giving more freedom of placing buildings as anything can be below these platforms.</p>
<h2 id="how-to-use">How to use</h2>
<p>All platforms can be found under the paths tab. You can place them to the side of any cliff or a stack of levees.</p>
<h2 id="middle-platform">Middle Platform</h2>
<p><del>These platforms can be placed nearly everywhere. They can be placed against any cliff, platform, building etc. It should be noted that this makes it possible to make floating buildings and as such is not advised when you like reality and game integrity.</del></p>
<h2 id="problems">Problems?</h2>
<p>In case you experience problems, please click <a href="https://mod.io/g/timberborn/r/troubleshooting-mod-setup"> THIS LINK </a> to go to a page containing the most frequent issues and see if yours is included. If your issue is not there, it can be the game or something changed which makes it result in a crash. If you are savvy enough, try to look for the mods that is making the game crash. If you determine that its this mod, then please message me in the modding channel of the the Timberborn discord. Or you can leave a comment below asking for help.</p>
<p>IMPORTANT: Make sure to provide as much information as you can about the problem. Without more information, I cannot help you. Think about the following: What mods you have installed? What version you using? What happened before the crash? Anything the could help me reproduce and find the issue to be able to fix it. I will try to fix it as soon as possible. :D</p>
